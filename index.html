My Selected Project

Visual Annotation - Practice Project

A practice excercise in reviewing an image and applying clear labels.

Annotation Rules

  • Label only what is visible in the image.
  • Use "uncertain" when there is not enough evidence.
  • Do not assume an action just because an object is present.

Sample 01: Image Labels

  • Person present: Yes
  • Number of visible people: 1
  • Visible action: Holding an ice cream cone
  • Eating: Not visible
  • Indoor or outdoor setting: Uncertain

Annotation Decision

The person (female) is holding the cone away from their mouth. Holding is visible, but eating cannot be confirmed. The dark background does not establish whether the location is indoors or outdoors.
